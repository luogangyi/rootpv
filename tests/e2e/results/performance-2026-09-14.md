# RootPV 性能测试结果

- 日期：2026-09-14
- 环境：Kubernetes v1.29；6 节点 x86_64 Linux 集群；目标节点使用 containerd 2.1.1+aiinfra
- 存储：动态块存储 PVC，最小容量 10Gi
- 镜像：预加载到目标节点的 RootPV amd64 测试镜像
- 预热轮数：1
- 未启用 RootPV 迭代次数：3
- 启用 RootPV 迭代次数：3
- 每轮根文件系统写入：64 MiB

| 指标 | 未启用 RootPV | 启用 RootPV | 性能损耗占比 |
| --- | ---: | ---: | ---: |
| Pod 创建至 Running（平均 / P95） | 5517 / 5736 ms | 13685 / 14726 ms | 平均 +148.05%；P95 +156.73% |
| 根文件系统顺序写入（平均 / P95） | 1919 / 1987 ms | 2082 / 2153 ms | 平均 +8.49%；P95 +8.35% |
| Pod 删除与运行时清理（平均 / P95） | 32451 / 32668 ms | 32772 / 33055 ms | 平均 +0.99%；P95 +1.18% |
| 根文件系统顺序写入吞吐量 | 33.36 MiB/s | 30.73 MiB/s | 7.88% |

未启用 RootPV 时写入容器可写层；启用 RootPV 时写入持久根目录。两者差异代表启用持久根目录的端到端成本，并非仅 runtime wrapper 的开销。逐轮结果见同目录的 CSV 文件。已完成测试命名空间及 PVC 清理。
