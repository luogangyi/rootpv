# RootPV 性能测试结果

- 日期：2026-09-03
- 环境：Kubernetes v1.29；多节点 x86_64 Linux 集群；目标节点使用 containerd 2.1
- 存储：动态块存储 PVC，最小容量 10Gi
- 镜像：预加载到目标节点的 RootPV amd64 测试镜像
- 预热轮数：1
- 未启用 RootPV 迭代次数：3
- 启用 RootPV 迭代次数：3
- 每轮根文件系统写入：64 MiB

| 指标 | 未启用 RootPV | 启用 RootPV | 性能损耗占比 |
| --- | ---: | ---: | ---: |
| Pod 创建至 Running（平均 / P95） | 5500 / 5700 ms | 14560 / 15553 ms | 平均 +164.73%；P95 +172.86% |
| 根文件系统顺序写入（平均 / P95） | 1910 / 1972 ms | 1995 / 2066 ms | 平均 +4.45%；P95 +4.77% |
| Pod 删除与运行时清理（平均 / P95） | 32336 / 32440 ms | 32247 / 32519 ms | 平均 -0.28%；P95 +0.24% |
| 根文件系统顺序写入吞吐量 | 33.50 MiB/s | 32.08 MiB/s | 4.24% |

未启用 RootPV 时写入容器可写层；启用 RootPV 时写入持久根目录。两者差异代表启用持久根目录的端到端成本，并非仅 runtime wrapper 的开销。逐轮结果见同目录的 CSV 文件。已完成测试命名空间及 PVC 清理。
